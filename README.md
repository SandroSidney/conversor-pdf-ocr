## **Conversor de arquivos PDFs não pesquisavel para pesquisavel**
 
Transformar arquivos PDF não pesquisavel para pesquisavel. É utilizado dois apps para passar o OCR.

*obs: Os testes foram realizados Windows 11.*


### Quick Start

*Ativar ambiente virtual

```bash
# 1. Ativar ambiente virtual 
python -m venv .venv

# 2. Alterar para o diretório do ambiente virtual - (Windows)
.venv\Scripts\activate 

# 3. Instalar as bibliotecas
    #Biblioteca OCRmyPDF converter PDF digitalizado em PDF pesquisável
	
pip install ocrmypdf os

```
